📊 Naiyo24 Admin Panel

The Naiyo24 Admin Panel is a modern, high-performance web dashboard built to manage and monitor core business operations of Naiyo24 Pvt. Ltd.
It provides administrators with a centralized interface to analyze data, manage services, track growth metrics, and generate reports efficiently.

Built using React + Vite + TypeScript, the application focuses on scalability, performance, and clean UI/UX while following industry-standard frontend practices.

🚀 Key Features

📈 Interactive Analytics Dashboard
Visual insights using dynamic charts and graphs for growth, services, and performance metrics.

🧾 PDF Report Generation
Export structured data and reports using jsPDF & jsPDF-AutoTable.

⚡ Fast & Optimized Build
Powered by Vite for lightning-fast development and production builds.

🧩 Reusable Component Architecture
Clean, modular, and scalable React components.

🎨 Modern UI & Icons
Responsive design with Lucide Icons and smooth UI interactions.

🔒 Admin-Focused Design
Built specifically for internal administrative use and operational control.

🛠️ Tech Stack

Frontend: React, TypeScript

Build Tool: Vite

Charts & Visualization: Custom chart components

PDF Generation: jsPDF, jsPDF-AutoTable

Icons: Lucide-React

Styling: CSS / Tailwind (if applicable)

📂 Use Cases

Business analytics & performance tracking

Service distribution monitoring

Admin-level data management

Downloadable reports for internal reviews
